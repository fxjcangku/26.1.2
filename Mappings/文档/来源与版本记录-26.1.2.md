# Fabric 26.1.2 API 来源与版本记录

## 项目定位

本目录是 Fabric 26.1.2 的官方命名 API 速查与迁移辅助资料，不是 Yarn 映射仓库，也不保存 Mojang 的传统映射原文件。

| 项目 | 当前值 |
|---|---|
| Minecraft | 26.1.2 |
| Minecraft 内部兼容标识 | 1.21.11 |
| 开发平台 | Fabric |
| Loom | 1.16-SNAPSHOT，需以项目实际缓存和官方文档为准 |
| Fabric Loader | 0.19.3 |
| Java | 25 |
| 命名空间 | official |
| 混淆状态 | 26.1 起使用官方非混淆代码 |
| API JAR 来源 | 项目 `.gradle/loom-cache` 中的 Minecraft merged JAR |

## 本地事实来源

优先级从高到低如下：

1. 项目 `.gradle/loom-cache` 中实际解析的 Minecraft 26.1.2 merged JAR。
2. 编译器和 IDE 解析到的项目依赖。
3. Fabric 官方 26.1.2 文档与 Fabric API 改名表。
4. `Mappings/` 下由本地 JAR 生成的类名和包路径索引。
5. 已迁移的第三方项目，仅用于理解调用方式，不作为 API 事实来源。

## 生成和查询

在项目根目录执行：

```powershell
node Mappings\工具\从MinecraftJAR生成索引.js
node Mappings\工具\查JARAPI.js Minecraft
node Mappings\工具\查JARAPI.js LocalPlayer sendSystem
node Mappings\工具\查JARAPI.js --找 sendCommand
```

如果本地没有 Minecraft merged JAR，先执行一次：

```powershell
.\gradlew.bat classes
```

脚本会自动从 `.gradle/loom-cache` 查找 `minecraft-merged-*26.1.2.jar`，不需要下载传统 `client_mappings` 或 `server_mappings`。

## 与旧版本的区别

| 旧开发方式 | Fabric 26.1.2 |
|---|---|
| Yarn 映射 | 不作为当前项目开发命名空间 |
| `mappings loom.officialMojangMappings()` | 不配置 |
| `fabric-loom-remap` | 不用于 26.1 开发链路 |
| `modImplementation` | 非混淆流程按官方文档使用普通依赖配置 |
| `remapJar` | 26.1 使用普通 `jar` |
| `ResourceLocation` | `Identifier` |
| `MinecraftClient` | `Minecraft` |
| `ClientPlayerEntity` | `LocalPlayer` |
| `Text` | `Component` |
| `Vec3d` | `Vec3` |
| `World` | `Level` |

## Fabric API 单独核对

Minecraft 官方命名变化和 Fabric API 改名是两套变化，不能只靠 Minecraft 类索引判断。26.1 常见 Fabric API 改名包括：

| 旧名称 | 26.1 名称 |
|---|---|
| `ClientCommandManager` | `ClientCommands` |
| `ClientWorldEvents` | `ClientLevelEvents` |
| `StartWorldTick` | `StartLevelTick` |
| `KeyBindingHelper` | `KeyMappingHelper` |
| `ParticleFactoryRegistry` | `ParticleProviderRegistry` |
| `FabricDataOutput` | `FabricPackOutput` |
| `FabricTagProvider` | `FabricTagsProvider` |
| `WorldRenderEvents` | `LevelRenderEvents` |

完整改名以 Fabric 官方迁移页面为准。

## 不再使用的旧工具

`工具/下载官方映射.ps1` 保留用于历史版本研究，不属于 26.1.2 的正常初始化步骤。26.1.2 的 API 索引应从实际 Minecraft JAR 生成，避免依赖不存在的 `client_mappings` 和 `server_mappings` 字段。
