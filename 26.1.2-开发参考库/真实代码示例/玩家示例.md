# 玩家示例

## 概述

26.1.2 里「玩家」就是客户端本体的 `net.minecraft.client.player.LocalPlayer`（`mc.player`），继承链 `Entity → LivingEntity → Player → LocalPlayer`。所有玩家操作按获取入口分三类：

| 类别 | 入口 | 说明 |
| --- | --- | --- |
| 坐标 | `mc.player.getX()/getY()/getZ()`、`blockPosition()`、`position()` | 双精度 / 方块格 / Vec3 |
| 视角 | `getYRot()/getXRot()`、`setYRot()/setXRot()` | 偏航/俯仰，单位是度 |
| 移动/状态 | `setDeltaMovement()`、`getDeltaMovement()`、`onGround()`、`isSprinting()`、`isAlive()` | 速度向量、落地、疾跑、存活 |

Meteor 本体把常用玩家工具收在 `meteordevelopment.meteorclient.utils.player.PlayerUtils`，本项目模块直接调用它或复刻同类逻辑。注意 26.1.2 是**官方映射**：视高是 `mc.player.getEyeHeight(...)`、可交互距离是 `mc.player.blockInteractionRange()`，而不是旧 Yarn 名。

## 示例 1：玩家距离 / 可达范围 / 存活 / 游戏模式 / 延迟

出处：`Meteor原始源码/meteordevelopment/meteorclient/utils/player/PlayerUtils.java`（第 269-273 行、第 337-339 行、第 351-356 行、第 362-372 行）

```java
// 两点平方距离（用 FMA 优化，避免嵌套 Math.pow）
public static double squaredDistance(double x1, double y1, double z1, double x2, double y2, double z2) {
    double f = x1 - x2;
    double g = y1 - y2;
    double h = z1 - z2;
    return org.joml.Math.fma(f, f, org.joml.Math.fma(g, g, h * h));
}

// 是否在对方块交互范围内
public static boolean isWithinReach(double x, double y, double z) {
    return squaredDistance(mc.player.getX(), mc.player.getEyeY(), mc.player.getZ(), x, y, z)
        <= mc.player.blockInteractionRange() * mc.player.blockInteractionRange();
}

// 获取当前游戏模式（通过玩家列表条目，不是 mc.gameMode）
public static GameType getGameMode() {
    if (mc.player == null) return null;
    PlayerInfo playerListEntry = mc.getConnection().getPlayerInfo(mc.player.getUUID());
    if (playerListEntry == null) return null;
    return playerListEntry.getGameMode();
}

// 存活判断
public static boolean isAlive() {
    return mc.player.isAlive() && !mc.player.isDeadOrDying();
}

// 获取网络延迟
public static int getPing() {
    if (mc.getConnection() == null) return 0;
    PlayerInfo playerListEntry = mc.getConnection().getPlayerInfo(mc.player.getUUID());
    if (playerListEntry == null) return 0;
    return playerListEntry.getLatency();
}
```

要点：
- 距离一律用 `squaredDistance` 与阈值平方比，避免开根号损耗；`isWithinReach` 的可交互距离是 `mc.player.blockInteractionRange()`。
- 游戏模式从 `mc.getConnection().getPlayerInfo(uuid).getGameMode()` 拿才是服务端认定的；`mc.gameMode` 是本地交互控制器。
- 延迟 `getLatency()` 是 `PlayerInfo` 的方法。

## 示例 2：玩家朝向某坐标的 yaw/pitch 计算

出处：`src/main/java/com/example/addon/modules/AutoBoneMeal.java`（第 604-613 行）

```java
import net.minecraft.network.protocol.game.ServerboundMovePlayerPacket;
import net.minecraft.world.phys.Vec3;

private void sendSilentRotation(Vec3 target) {
    Vec3 eye  = mc.player.getEyePosition();
    Vec3 diff = target.subtract(eye);
    double horizDist = Math.sqrt(diff.x * diff.x + diff.z * diff.z);
    float pitch = (float) -Math.toDegrees(Math.atan2(diff.y, horizDist));
    float yaw   = (float)  Math.toDegrees(Math.atan2(diff.z, diff.x)) - 90f;
    mc.getConnection().send(
        new ServerboundMovePlayerPacket.Rot(yaw, pitch, mc.player.onGround(), mc.player.horizontalCollision)
    );
}
```

要点：
- `getEyePosition()` 返回眼睛中心 Vec3（含视高），比拿脚底坐标算角度更准。
- yaw 公式 `atan2(dz, dx) - 90°`、pitch `-atan2(dy, 水平距)`，是原版视角的稳定写法——「静默视角」：**发包只改服务端视角，客户端的 `setYRot/setXRot` 不调用**，实现隔墙交互而不转动玩家视线。

## 示例 3：读视角 + 方块坐标（指令里取玩家状态）

出处：`src/main/java/com/example/addon/commands/WKCommand.java`（第 234-236 行、第 458-463 行）

```java
// 记录挂机修复点：站位 + 视角
BlockPos pos = mc.player.blockPosition();
float yaw = mc.player.getYRot();
float pitch = mc.player.getXRot();

// 取准星对准的方块（未对准返回 null）
private BlockPos getTargetBlock() {
    HitResult hit = mc.hitResult;
    if (hit == null || hit.getType() != HitResult.Type.BLOCK) return null;
    if (!(hit instanceof BlockHitResult blockHit)) return null;
    return blockHit.getBlockPos().immutable();
}
```

要点：
- `blockPosition()` 返回脚下所在的**整格 `BlockPos`**；`position()` 返回脚底双精度 `Vec3`；`getEyePosition()` 返回眼睛 Vec3。
- 准星命中的最新结果总是在 `mc.hitResult`，先判类型 `HitResult.Type.BLOCK` 再转 `BlockHitResult`，`getBlockPos()` 建议 `.immutable()` 防止被共享引用污染。

## 示例 4：玩家居中 + 发位置包（反居中偏移）

出处：`Meteor原始源码/meteordevelopment/meteorclient/utils/player/PlayerUtils.java`（第 108-113 行）

```java
import net.minecraft.util.Mth;

public static void centerPlayer() {
    double x = Mth.floor(mc.player.getX()) + 0.5;
    double z = Mth.floor(mc.player.getZ()) + 0.5;
    mc.player.setPos(x, mc.player.getY(), z);
    mc.player.connection.send(new ServerboundMovePlayerPacket.Pos(
        mc.player.getX(), mc.player.getY(), mc.player.getZ(),
        mc.player.onGround(), mc.player.horizontalCollision));
}
```

要点：
- 把玩家贴到格中心 `floor(x)+0.5`，避免站在方块边缘导致寻路/交互判定漂移。
- `setPos` 只改客户端，必须补发 `ServerboundMovePlayerPacket.Pos` 同步服务端。

## 模式要点

1. **坐标三件套**：`position()`（Vec3 脚底）、`blockPosition()`（BlockPos 整格）、`getEyePosition()`（Vec3 眼睛，含 `getEyeHeight()`）。
2. **视角读写**：`getYRot()/getXRot()` 读取、`setYRot()/setXRot()` 写客户端；若要「只欺骗服务端」就只发包 `ServerboundMovePlayerPacket.Rot` 不改客户端视角（静默视角）。
3. **移动速度**：`getDeltaMovement()`（Vec3），水平速度 `getDeltaMovement().horizontalDistance()`，Y 轴 `getDeltaMovement().y`；发包飞行时直接 `setDeltaMovement(...)` + 伪造 onGround（见「Packet 示例」）。
4. **状态判断**：`onGround()` 落地、`horizontalCollision` 横向贴墙、`isSprinting()` 疾跑、`isAlive() && !isDeadOrDying()` 存活、`getHealth()` 生命、`getAbsorptionAmount()` 吸收血量。
5. **空值防护**：Tick/渲染事件里 `mc.player` 可能 null（主菜单），任何玩家操作前必须先判 `mc.player == null`。

## 常见坑

- **把 `getEyeY()` 当成 Yarn 旧名**：26.1.2 官方映射方法是 `getEyeY()`（全小写），旧 Yarn `getEyePos().y`/`getEyeHeight` 不要混用；视高 `Pose` 版本是 `getEyeHeight(mc.player.getPose())`。
- **交互距离写死 `4.5` / `6.0`**：26.1.2 用属性系统，方块交互范围是 `mc.player.blockInteractionRange()`、实体是 `mc.player.entityInteractionRange()`，写死会因服务器改属性而误判。
- **忘记 `.immutable()`**：`getBlockPos()` 返回的 BlockPos 可能复用，若后续 `offset()` 修改会污染原引用。
- **角度没归一化**：`atan2` 结果纬度可能越界，需要时用 `Mth.wrapDegrees(...)` 归一化到 [-180, 180]。
- **用 `mc.gameMode.getPlayerMode()` 判模式**：本地枚举与服务端认定可能不一致，应走 `getPlayerInfo(uuid).getGameMode()`。

## 26.1.2 注意

- **`mc` 单例是 `MeteorClient.mc`**（静态）,任何类里 `import static meteordevelopment.meteorclient.MeteorClient.mc;` 后直接用 `mc.player`。
- **`getEyeY()` vs `getEyeHeight()`**：前者返回当前眼睛绝对 Y，后者返回视高偏移，二者别混。
- **`isDeadOrDying()` 是 26.1.2 新增判定**，比旧 `isDead()` 覆盖了「死亡动画播放中」的过渡态。
- **玩家输入在 `mc.player.input`**（`net.minecraft.world.entity.player.Input`），按键判断 `mc.player.input.keyPresses.forward()` 等（`PlayerUtils.getHorizontalVelocity` 第 76 行用法），不是旧 Yarn 的 `mc.options.keyForward`。
- **`ServerboundMovePlayerPacket.Rot` 需要 `horizontalCollision` 参数**：从 `mc.player.horizontalCollision` 字段读，构造第 4 参必须传。
