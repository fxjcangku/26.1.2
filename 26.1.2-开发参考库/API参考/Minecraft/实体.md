# 实体（Entity）

> 源码依据：Minecraft原始源码/net/minecraft/world/entity/ 26.1.2 Mojang官方映射

## Entity（net.minecraft.world.entity.Entity）

- 包名：`net.minecraft.world.entity`
- 源码路径：`net/minecraft/world/entity/Entity.java`
- 继承与接口：`public abstract class Entity`（抽象基类，实现 `Nameable`、`EntityLike`、`CommandSource`；是 `LivingEntity`、`Mob`、`Player` 的共同祖先）。

### 关键字段（源码真实名）

| 字段 | 类型 | 说明 |
|------|------|------|
| `position` | `private Vec3 position` | 精确位置，`position()` 返回 |
| `blockPosition` | `private BlockPos blockPosition` | 所在方块坐标缓存，`blockPosition()` 返回 |
| `deltaMovement` | `private Vec3 deltaMovement = Vec3.ZERO` | 速度/位移向量 |
| `xOld/yOld/zOld` (渲染用 `xo/yo/zo`) | `public double` | 上一 tick 位置（`xo/yo/zo` 是渲染插值用） |
| `yRot` / `xRot` | `private float` | 偏航/俯仰（度），`getYRot()/getXRot()` 读取 |
| `yRotO` / `xRotO` | `public float` | 上一 tick 朝向 |
| `onGround` | `private boolean` | 着地（仅实体自身看法，`onGround()`） |
| `horizontalCollision` / `verticalCollision` / `verticalCollisionBelow` / `minorHorizontalCollision` | `public boolean` | 碰撞标记 |
| `noPhysics` | `public boolean` | 无碰撞/无物理 |
| `tickCount` | `public int` | 已存在 tick 数 |
| `invulnerableTime` | `public int` | 受伤无敌帧（`hurtTime` 在 LivingEntity） |
| `fallDistance` | `public double` | 摔落距离 |

## EntityType（net.minecraft.world.entity.EntityType）

- 源码路径：`net/minecraft/world/entity/EntityType.java`
- 继承与接口：`public class EntityType<T extends Entity>`（大量静态字段是 `EntityType<? extends ...>` 的注册实例）。

### 客户端常用入口

```java
public EntityType<?> getType();          // 来自 Entity.getType()，判断实体种类
public ResourceKey<EntityType<?>> ...    // 通过 BuiltInRegistries.ENTITY_TYPE.getKey(type) 拿注册名
```

判断是否为某类实体通常用 `instanceof`（如 `entity instanceof Player`、`entity instanceof LivingEntity`），再用 `entity.getType()` 比对注册键即可。`BuiltInRegistries.ENTITY_TYPE` 是一个 `DefaultedRegistry<EntityType<?>>`，默认值 `pig`。

## 常见坑

1. **`getDeltaMovement()` 返回可变 Vec3，`setDeltaMovement` 会校验有限性**：非有限值（NaN/Inf）会被静默忽略，写速度前确保有限。
2. **`position()` 返回的是内部引用**：直接改 `position().x` 无效且危险，改位置必须用 `setPos`/`setPosRaw`/`teleportTo`。
3. **`BlockPos` 不可变**：`blockPosition()` 是缓存，位置变了会自动重算；不要对返回的 `BlockPos` 做可变修改（`BlockPos` 本身 `@Immutable` 语义，需 `MutableBlockPos`/`offset()` 返回新对象）。
4. **客户端伤害要区分 `hurtClient`（表现）与 `hurtServer`（真实结算）**：Meteor 客户端无法“真正”伤害服务端实体，只能发攻击包（`mc.gameMode.attack(...)`）；本地改 `setHealth` 只是视觉。
5. **`Entity.isAlive` vs `LivingEntity.isAlive`**：基类判断 `!isRemoved`，LivingEntity 多判 `getHealth()>0`；用 `entity.isAlive()` 时要清楚接收者类型。`isRemoved()` 未在本清单列出——源码里由 `removalReason != null` 体现，判存活优先 `isAlive()`。
