# 移动（Movement）

> 源码依据：Minecraft原始源码/net/minecraft/world/entity/（Entity、LivingEntity、MoverType、player/Input）与 net/minecraft/client/player/（LocalPlayer、ClientInput） 26.1.2 Mojang官方映射

客户端 addon 视角的移动分三层：**速度字段**（`getDeltaMovement` 一套，直接改）、**移动执行**（`move`/`moveRelative`）、**输入驱动**（`LocalPlayer.input` → `applyInput` → `travel`）。做「飞行绕检 / 加速」类功能都在这一层动手。

---

## Entity 移动核心（net.minecraft.world.entity.Entity）

- 源码路径：`net/minecraft/world/entity/Entity.java`

### 关键字段（源码真实名）

| 字段 | 类型 | 说明 |
|------|------|------|
| `position` | `private Vec3` | 坐标（用 `position()` 读，`setPos` 写） |
| `stuckSpeedMultiplier` | `protected Vec3` | 卡住速度乘数，恒 `Vec3.ZERO` |
| `onGround`（setter 维护） | `private boolean` | 是否在地面（`onGround()` 读） |
| `shiftKeyDown` | `private boolean` | 潜行（`setShiftKeyDown` 写） |

### 关键方法（签名照抄源码）

```java
// 速度（客户端 addon 改移动最常用）
public Vec3 getDeltaMovement();                          // 当前每 tick 位移向量（含 y 重力/下落）

public void setPos(double x, double y, double z);
public void teleportTo(double x, double y, double z);    // 传送（客户端发包）
public void absMoveTo(double x, double y, double z, float yRot, float xRot);

// 地面 / 潜行
public void setOnGround(boolean onGround);

// 朝向
public Vec3 getLookAngle(); public Vec3 getForward();

// 渲染插值（防抖，非物理）

public Vec3 getKnownSpeed();
```

### MoverType（net.minecraft.world.entity.MoverType）

```java
public enum MoverType { SELF, PLAYER, PISTON, SHULKER_BOX, SHULKER; }
```

> 玩家/生物自己走用 `MoverType.SELF`；`PLAYER` 是骑乘/被玩家主动推动时的分类。`move` 第一个参数影响「是否触发方块特殊碰撞（活塞/潜影盒）」。

## LivingEntity 移动（net.minecraft.world.entity.LivingEntity）

- 源码路径：`net/minecraft/world/entity/LivingEntity.java`

### 关键字段（源码真实名）

```java
public float xxa;             // 相对左(-1)~右(+1) 输入（applyInput/手写写入）
public float yya;             // 相对前后轴……实际前后在 zza，yya 供飞行/游泳纵向
public float zza;             // 相对前(+1)~后(-1) 输入
protected boolean jumping;    // 是否在跳跃
private float speed;          // 地面移动速度（getSpeed() 返回，默认 0.1）
```

### 关键方法（签名照抄源码）

```java
public void travel(Vec3 input);                          // LivingEntity 移动总入口（分飞行/水中/空气三路）
public float getSpeed();                                 // 陆地移动速度（可覆写）
public void setSprinting(boolean isSprinting);
public boolean isSprinting();
public void jumpFromGround();                            // 起跳

// 内部移动实现（travel 内部调用，覆写拦截点）
protected void travelFlying(Vec3 input, float speed);    // 创造飞行：air 阻率 0.91
protected void travelInAir(Vec3 input);                  // 空气/地面：摩擦 0.98/0.91
```

`travel` 的输入 `input` 是「相对方向向量」，由 `xxa/zza/yya/jumping` 组合而来（`applyInput` 写入后由 `aiStep`/`travel` 消费）。覆写 `travel(Vec3)` 是拦截玩家移动最常用 hook（Mixin 注入点）。

- 输入不再是 Yarn 的 `MovementInput`，26.1.2 拆成两层：`ClientInput`（含按键 `Input` + 移动向量 `Vec2`）。

### 关键字段


### 关键方法（签名照抄源码）

## 移动链路速记

```text
玩家键盘 ──> LocalPlayer.input.keyPresses (Input) + input.getMoveVector() (Vec2)
   └─ applyInput()：xxa = moveVector.x, zza = moveVector.y, jumping = keyPresses.jump
        └─ aiStep()/travel()：把 xxa/zza/jumping 组合成相对 input Vec3
             └─ travelFlying / travelInAir / travelInWater
                  └─ moveRelative(speed, input) -> move(MoverType.SELF, deltaMovement)
```

飞行与水中分别走 `travelFlying`（空气阻率 0.91）与 `travelInWater`（见 LivingEntity 源码 2395/2452 行），想要「飞行不被服务端踢」通常要覆写 `travel` 或 `applyInput` 而非只改 `abilities.flying`（参见飞行绕过审计报告，案例不在本 API 文档范围）。

## 常见坑

1. **改 `abilities.flying` 不等于会飞**：飞行是「能力 + `travel` 实现」共同决定；只置位 `flying/mayfly` 而不走 `travelFlying` 分支，客户端不会真正进入飞行移动，还会与服务端预测脱节。
2. **`getDeltaMovement` 每个 tick 会变**：`move` 后、`setDeltaMovement` 前含重力累积；想稳定控制要「读当前值 → 覆盖/叠加 → 交给 `move`」，别期望长期持有同一 Vec3。
3. **`setPos` ≠ 传送**：`setPos` 只改本地坐标不发包；客户端想要旁人可见的移动要走 `move()` 或 `teleportTo()`，否则服务端瞬间拉回（瞬移异常，>200 格会触发异常检测薄弱项）。
4. **`xxa/zza/yya` 是相对轴不是世界轴**：`xxa` 左右、`zza` 前后；`travel` 内部会按 yaw 旋转成世界向量，直接给世界坐标会走歪。
5. **输入要走 `input` 才会被服务端同步**：改 `xxa` 只影响本地逻辑不产生发包语义，`LocalPlayer.applyInput()` 每 tick 会从 `input` 覆盖 `xxa/zza`；想驱动玩家移动改 `input.keyPresses/getMoveVector`（或覆写 `applyInput`），而不是改 `xxa`。
6. **渲染平滑用 `getKnownMovement`，物理用 `getDeltaMovement`**：混淆两者会让「显示位置」与「逻辑位置」错位，视觉瞬移但碰撞仍在原地。
