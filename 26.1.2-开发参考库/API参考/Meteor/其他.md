# 其他（Meteor 杂项高频 API）

> 源码依据：Meteor原始源码/meteordevelopment/meteorclient/utils/... 、systems/... 、gui/... Meteor Client 26.1.2-SNAPSHOT

本文整理 addon 开发中除方块/实体/渲染/命令/Addon/Mixin 之外的高频杂项：`Utils`、`mc` 单例、`ChatUtils`、`ICopyable`/`ISerializable`、`Keybind`，以及 systems（Hud / waypoints / config / macros 等）与 GUI 主题。

---

## mc 单例引用方式（重要）

- `mc` 是 **`MeteorClient.mc`** 静态字段：`public static Minecraft mc;`（`meteordevelopment\meteorclient\MeteorClient.java`），在 `onInitializeClient()` 里 `mc = Minecraft.getInstance();`。
- 事件总线：`MeteorClient.EVENT_BUS`（`public static final IEventBus`，来自 `meteordevelopment.orbit`）。
- 常用常量：`MeteorClient.MOD_ID`（`"meteor-client"`）、`MeteorClient.FOLDER`（配置目录 `游戏根目录/meteor-client`）、`MeteorClient.ADDON`（Meteor 伪 addon）、`MeteorClient.identifier(String path)`。
- addon 内一般 `import static meteordevelopment.meteorclient.MeteorClient.mc;`。
- **注意**：`Utils` 里没有 `mc` 字段（已核实 `Utils.java` 只有静态工具方法）。旧版「Utils.mc / MC.get()` 记忆有误。

## ICopyable / ISerializable

### 类名与包名
`meteordevelopment.meteorclient.utils.misc.ICopyable`
`meteordevelopment.meteorclient.utils.misc.ISerializable`

### 源码路径
`utils/misc/ICopyable.java`、`utils/misc/ISerializable.java`

```java
public interface ICopyable<T extends ICopyable<T>> {
    T set(T value);
    T copy();
}

public interface ISerializable<T> {
    CompoundTag toTag();
    T fromTag(CompoundTag tag);
}
```
- 用途：设置值对象（`Color`、`Keybind`、`SettingColor` 等）通用「拷贝 / NBT 序列化」约定。自定义设置类型实现这两个接口即可被 Meteor 设置系统接管序列化。

## systems（各系统概况 + 关键 API）

所有系统都继承 `meteordevelopment.meteorclient.systems.System<T>`，通过 `Systems.get(Class<T>)` 获取单例，配置存在 `MeteorClient.FOLDER` 下。

### Systems
`meteordevelopment.meteorclient.systems.Systems`
```java
public static <T extends System<?>> T get(Class<T> klass)
public static System<?> add(System<?> system)
```

### Modules（模块系统）
`meteordevelopment.meteorclient.systems.modules.Modules`
```java
public static Modules get()
public static void registerCategory(Category category)
public <T extends Module> T get(Class<T> klass)
public boolean isActive(Class<? extends Module> klass)
public void add(Module module)
```
- 分类：`Categories`（`systems/modules/Categories.java`）持有内置分类。

### Hud（HUD 系统）
`meteordevelopment.meteorclient.systems.hud.Hud`
- `public class Hud extends System<Hud> implements Iterable<HudElement>`
- `public static final HudGroup GROUP`；字段 `active`、`settings`，`Setting<Double> textScale`、`Setting<Integer> border` 等。
- `public static Hud get()`；`public void register(HudElementInfo<?> info)`。
- addon 添加 HUD 元素：`Hud.get().register(MyHudElement.INFO)`。

### Waypoints（坐标点系统）
`meteordevelopment.meteorclient.systems.waypoints.Waypoints`
- `public static Waypoints get()`
- `public boolean add(Waypoint waypoint)` / `public boolean remove(Waypoint waypoint)`
- `public Waypoint get(String name)` / `removeAll(Collection<Waypoint>)`
- `public final Map<String, AbstractTexture> icons`；`BUILTIN_ICONS`。
- 添加/移除都会 post `WaypointAddedEvent` / `WaypointRemovedEvent`。

### Config（全局配置）
`meteordevelopment.meteorclient.systems.config.Config`
- `public static Config get()`
- 关键设置：`prefix`（`Setting<String>` 命令前缀）、`customFont`、`font`、`rainbowSpeed`、`deleteChatFeedback` 等。
- 使用：`Config.get().prefix.get()` 拿当前命令前缀。

### Macros（宏系统）
`meteordevelopment.meteorclient.systems.macros.Macros`
- `public static Macros get()`
- `public void add(Macro macro)` / `public Macro get(String name)` / `public void remove(Macro macro)`
- `public List<Macro> getAll()` / `isEmpty()`。
- add 时会自动 `EVENT_BUS.subscribe(macro)` 并保存。

### 其他系统（同目录，致概览）
- `friends`（`systems/friends/Friends.java`：好友列表，`Friends.get().shouldAttack(Player)`）
- `accounts`（`systems/accounts/`：账号管理）
- `profiles`（`systems/profiles/`：配置文件切换）
- `proxies`（`systems/proxies/`：代理管理）

## GUI 主题 / 屏幕

### GuiThemes
`meteordevelopment.meteorclient.gui.GuiThemes`
- 静态管理全局 GUI 主题。
- `public static void add(GuiTheme theme)` / `public static void select(String name)` / `public static GuiTheme get()`
- 内置 `MeteorGuiTheme`（`gui/themes/meteor/MeteorGuiTheme.java`），主题存 `meteor-client/gui/gui.nbt`。

### WidgetScreen
`meteordevelopment.meteorclient.gui.WidgetScreen`
- Meteor 所有自定义界面的基类（`extends Screen`）。`Tabs.get().getFirst().openScreen(GuiThemes.get())` 打开主界面。
- `MeteorClient` 里通过 `event.screen instanceof WidgetScreen` 判断是否需要隐藏原版 HUD。

## 常见坑
1. `mc` 要从 `MeteorClient.mc` 取，别找 `Utils.mc`（26.1.2 不存在）。
2. 几乎所有 `onTick` 类逻辑先判 `Utils.canUpdate()`，否则进服前 `mc.level`/`mc.player` 为 null 直接 NPE。
3. `ChatUtils.sendPlayerMsg` 会把消息当「玩家真的输入」发送（含历史记录），用于机器人回复时注意与 `sendMsg`（客户端提示）区别。
4. `Keybind` 构造器私有，务必用 `Keybind.fromKey(...)` 等工厂；`Keybind.set(...)` 是实例方法用于配置回填。
5. 自定义设置类型要继承/实现 `ICopyable` + `ISerializable` 才能被 Meteor 设置系统正确序列化。
6. 系统单例一律 `Systems.get(Xxx.class)`，不要 `new`；配置读写由 `MeteorClient.onInitializeClient` 的 `Systems.load/save` 统一处理。
7. addon 注册 HUD/命令/模块后不需要手动 `save()`（系统会在卸载时统一保存配置）。
