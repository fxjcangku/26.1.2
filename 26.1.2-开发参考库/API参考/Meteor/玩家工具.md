# 玩家工具

玩家相关静态工具集中在 `meteordevelopment.meteorclient.utils.player`（`PlayerUtils`/`Rotations`/`Safety` 等）与 `utils.entity`（`DamageUtils`/`EntityUtils`）。玩家实体访问统一用 `MeteorClient.mc.player`（`MeteorClient.mc` 为 `public static Minecraft`）。

---

## 0. 玩家实体访问

`MeteorClient`（`meteordevelopment/meteorclient/MeteorClient.java`）：
```java
public static Minecraft mc;
```
常用访问：
- `MeteorClient.mc.player` → `LocalPlayer`（当前玩家）
- `MeteorClient.mc.level` → `ClientLevel`
- `MeteorClient.mc.getConnection()` → `ClientPacketListener`
- `MeteorClient.mc.gameMode` → `MultiPlayerGameMode`
- `MeteorClient.mc.gameRenderer` → 渲染
> 源码中普遍 `import static meteordevelopment.meteorclient.MeteorClient.mc;` 后直接 `mc.player`。`Utils.canUpdate()`（`utils/Utils.java`）判 `mc != null && mc.level != null && mc.player != null`，是进入世界与否的常用守卫。

## 常见坑
1. 26.1.2 中朝向工具**不叫 `RotationUtils`，叫 `Rotations`**；也不存在 `PositionUtils` 类（任务提到的 `PositionUtils` 本版源码查无，坐标/朝向用 `PlayerUtils` + `Rotations`）。
2. `Rotations.rotate(...)` 是「队列 + 下一次移动包」异步应用，调用后并非立刻改 `mc.player.getYRot()`；回调通过 callback 触发。
3. `PossibleHealthReductions` / 距离计算依赖 `mc.level`/`mc.player`，未进世界会 NPE，先 `Utils.canUpdate()` 或判空。
4. `DamageUtils` 在 `utils.entity`（不是 `utils.player`）包，import 路径别写错。
5. 距离比较优先用 `squaredDistance*` + `isWithin`，避免每次 `Math.sqrt`。
6. `Safety` 只是一个 `Safe/Suicide` 枚举，不含逻辑方法，别期待它有方法可调。
