# 问题检索地图（Troubleshooting）

> 查询顺序提醒：先查本地图 → 命中后到 原始源码 Grep 复核 → 再看 API参考对应文档
>
> 说明：按「现象/问题关键词」→「根因」→「解决方向」组织，覆盖 26.1.2 addon 开发最高频坑。每条末尾标注参考文档。

## 一、命名 / 类名混淆（Yarn 旧名已不存在）

| 问题关键词 | 根因 | 解决方向 | 参考文档 |
|-----------|------|----------|----------|
| `ResourceLocation` 找不到 | 26.1.2 官方名 `Identifier` | 一律 `net.minecraft.resources.Identifier`，`Identifier.parse(...)` | 注册表.md |
| `RegistryKey` 找不到 | 官方名 `ResourceKey` | `net.minecraft.resources.ResourceKey` | 注册表.md |
| `ClientConnection` / `ClientPlayNetworkHandler` | Yarn 旧名 | 用 `Connection` / `ClientPacketListener` | 网络.md |
| `PlayerEntity` / `ClientPlayerEntity` | Yarn 旧名 | 用 `Player` / `LocalPlayer` | 玩家.md |
| `MovementInput` | Yarn 旧名 | 26.1.2 用 `ClientInput` + `Input` | 玩家.md |
| `GuiGraphics` / `render(...)` / `renderSlot` | 旧版渲染 API | `GuiGraphicsExtractor` / `extractRenderState` / `extractSlot` | GUI与界面.md |
| `ChatFormatting` 位于 `net.minecraft.util` | 根包类 | import `net.minecraft.ChatFormatting` | 其他.md |
| `SlotActionType` | 旧枚举名 | 用 `ContainerInput`（PICKUP/QUICK_MOVE/...） | 物品与物品栏.md |
| `CommandArgumentType` | 26.1.2 已移除 | 用 `Command.argument(...)` / `literal(...)` | 命令.md |
| move 包旧名 `MovePlayerC2SPacket` | 旧命名 | `ServerboundMovePlayerPacket.*` 真实类 | 数据包.md |

## 二、判空 / NPE

| 问题关键词 | 根因 | 解决方向 | 参考文档 |
|-----------|------|----------|----------|
| 未进世界 NPE | `mc.player` / `mc.level` 为 null | 入口先判空或用 `Utils.canUpdate()` | 其他.md |
| `getConnection()` NPE | 未进世界返回 null | `if (mc.getConnection() != null)` 再 `.send*` | 网络.md |
| `gameMode()` null | 客户端模式未同步 | 用 `isCreative()`/`isSpectator()` 或 `mc.gameMode.getPlayerMode()` | 玩家.md |
| `getBlockEntity` null | 方块实体仅部分方块有 | 取完判 null 再 `.getComponent()` | 世界与方块.md |
| `getEffect` / `getPing` / `getGameMode` null | 网络信息未加载 | 非玩家/未同步时返回 null/0，需判空 | 实体工具.md |

## 三、物品 / 组件（NBT 已移除）

| 问题关键词 | 根因 | 解决方向 | 参考文档 |
|-----------|------|----------|----------|
| `getNbt()/setNbt()/getOrCreateTag()` 不存在 | 26.1.2 组件化，无 NBT | 用 `get(DataComponents.CUSTOM_DATA)` / `CustomData` | 物品与物品栏.md |
| `set(type, value)` 没改成 | 值语义，返回值是旧值 | 持有 `stack = stack.set(...)` 后的新实例 | 数据组件.md |
| `getComponents()` 改了不生效 | 返回快照 | `stack = stack.set/update(...)` 重新赋值 | 数据组件.md |
| 空物品判断 `== null` | 槽里是 `ItemStack.EMPTY` | 用 `stack.isEmpty()` | 物品与物品栏.md |
| `set(type, null)` 误删 | null 等价 remove | 写「空字符串/0」用非 null 值 | 数据组件.md |

## 四、附魔

| 问题关键词 | 根因 | 解决方向 | 参考文档 |
|-----------|------|----------|----------|
| `Enchantments.XXX` 不能直接当 Holder | 它是 `ResourceKey<Enchantment>` | 从 keySet 取 Holder 或 `lookup.getOrThrow(key)` | 附魔.md |
| `getLevel` 编译失败 | 参数需 `Holder<Enchantment>` | 传 Holder 而非 ResourceKey | 附魔.md |
| 互斥附魔判断写错 | 互斥已数据化 | 用 `Enchantment.areCompatible(a, b)` | 附魔.md |
| 直接改 `ItemEnchantments` 无效 | 不可变 | 经 `ItemEnchantments.Mutable` 改后写回组件 | 附魔.md |
| `getEnchantments()` 返回 null | 组件不存在 | 判 `stack.has(DataComponents.ENCHANTMENTS)` | 附魔.md |

## 五、方块 / 世界

| 问题关键词 | 根因 | 解决方向 | 参考文档 |
|-----------|------|----------|----------|
| `state.is(Blocks.STONE)` 编译失败 | 26.1.2 无 `is(Block)` | `state.getBlock() == Blocks.STONE` | 世界与方块.md |
| `BlockPos` 改了不生效 | 不可变 | `offset()/above()` 返回新对象，循环用 `MutableBlockPos` | 世界与方块.md |
| 放方块服务端不认 | `setBlock` 只改本地 | 用 `setBlockAndUpdate` 或走 `gameMode` 交互路径 | 世界与方块.md |
| 客户端挖方块无效 | 直接 `destroyBlock` 只改本地 | `gameMode.startDestroyBlock/continueDestroyBlock` | 世界与方块.md |
| `ClipContext` import 错 | 在 world.level | `net.minecraft.world.level.ClipContext` | 碰撞.md |
| `AABB.shrink` 不存在 | 26.1.2 名为 `contract` | `contract`/`deflate`/`expandTowards` | 碰撞.md |

## 六、移动 / 发包

| 问题关键词 | 根因 | 解决方向 | 参考文档 |
|-----------|------|----------|----------|
| 改 `abilities.flying` 不会飞 | 飞行需 travel 实现配合 | 覆写 `travel`/`applyInput` 而非只置位 flying | 移动.md |
| 改 `xxa` 不产生发包 | `applyInput` 每 tick 从 `input` 覆盖 | 改 `input.keyPresses/getMoveVector` | 移动.md |
| `setPos` 后瞬移被拉回 | `setPos` 只改本地不发包 | 用 `move()`/`teleportTo()` | 移动.md |
| 直接 new 抽象移动包 | `ServerboundMovePlayerPacket` 抽象 | new `Pos/PosRot/Rot/StatusOnly` | 数据包.md |
| 发包重入 StackOverflow | 监听器内再 send 触发事件 | 用 `event.sendSilently(packet)` | Packet数据包.md |
| 裸命令包被拒 | 服务端要求签名 | `sendCommand`/`sendUnattendedCommand` | 数据包.md |

## 七、事件 / Mixin

| 问题关键词 | 根因 | 解决方向 | 参考文档 |
|-----------|------|----------|----------|
| 监听器不生效 | 方法签名不符（非 void/参数≠1/原始类型） | 校验 `@EventHandler` + void + 1 个事件形参 | Event事件.md |
| import orbit.events 失败 | orbit 无 Event 基类/events 包 | import `meteordevelopment.orbit.EventHandler`；事件在 meteorclient.events | Event事件.md |
| 可取消事件取消后仍执行 | 优先级低 | 用 `EventPriority.HIGH` 数值大先执行 | Event事件.md |
| mixin 注入崩溃 | 方法名/描述符不匹配 | 目标字符串逐字匹配官方映射 | Mixin.md |
| mixin 静默不生效 | 未写进 mixins.json client 数组 | 登记到 `addon-template.mixins.json` | Mixin.md |
| 注入旧方法失败 | 如 `Screen.render` 已被替换 | 目标用 `extractRenderState` 等新方法 | Mixin.md、GUI与界面.md |

## 八、HTTP / 网络（Meteor）

| 问题关键词 | 根因 | 解决方向 | 参考文档 |

| `Http.send*` 返回 null | 非 200 状态返回 null | 处理响应判空 | Network网络.md |

## 十、快速自查清单

1. 类名是否官方映射（无 Yarn 名）？
2. `mc.player`/`mc.level`/`mc.getConnection()` 是否判空？
3. 物品/组件是否走 `set` 值语义重新赋值？
4. 附魔传参是 `Holder<Enchantment>` 还是 `ResourceKey`？
5. 方块比较是否 `state.getBlock() == Blocks.XXX`？
6. 发移动包用 `Pos/PosRot/Rot/StatusOnly` 子类，监听器内补发用 `sendSilently`？
7. 监听方法签名（void + 1 事件形参）与 `@EventHandler` 正确？
8. 新 mixin 是否写进 `addon-template.mixins.json` client 数组？
9. 新模块/命令/HUD 是否已在 `AddonTemplate` 注册？
10. 数值设置是否 `.noSlider()`、开关颜色开绿关红？
