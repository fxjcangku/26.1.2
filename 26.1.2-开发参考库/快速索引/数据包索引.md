# 数据包索引（Packet）

> 查询顺序提醒：先查本索引 → 命中后到 原始源码 Grep 复核 → 再看 API参考对应文档
>
> 说明：方向 `C→S` = Serverbound（客户端发出）/ `S→C` = Clientbound（服务端发出）。真实类名以 `Minecraft原始源码/net/minecraft/network/protocol/` 为准（26.1.2 用 `Serverbound*`/`Clientbound*` 前缀，无 Yarn 旧名 `C2S/S2C`）。方括号内为 Meteor 事件/工具。
