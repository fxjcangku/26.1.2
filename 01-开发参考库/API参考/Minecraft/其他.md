# 其他（杂项高频类）

> 源码依据：Minecraft原始源码/net/minecraft/... 26.1.2 Mojang官方映射

本文汇总客户端 addon 高频使用的杂项工具类：颜色、消息组件、通用工具、客户端输入、系统/平台工具等。以下内容均以 26.1.2 官方源码核实为准。

## 一、ChatFormatting（颜色/格式代码）

- 全限定名：`net.minecraft.ChatFormatting`（在根包 `net.minecraft`，**不是** `net.minecraft.util`）
- 源码路径：`net/minecraft/ChatFormatting.java`
- 声明：`public enum ChatFormatting implements StringRepresentable`

### 枚举常量（颜色）
`BLACK('0')、DARK_BLUE('1')、DARK_GREEN('2')、DARK_AQUA('3')、DARK_RED('4')、DARK_PURPLE('5')、GOLD('6')、GRAY('7')、DARK_GRAY('8')、BLUE('9')、GREEN('a')、AQUA('b')、RED('c')、LIGHT_PURPLE('d')、YELLOW('e')、WHITE('f')`

### 枚举常量（格式）
`OBFUSCATED('k')、BOLD('l')、STRIKETHROUGH('m')、UNDERLINE('n')、ITALIC('o')、RESET('r')`

### 关键方法（真实签名）
```java
public char getChar();      // 格式码字符（如 'c'）
public int getId();         // 颜色 id（格式类返回 -1）
public boolean isColor();   // 是否颜色（排除格式与 RESET）
public boolean isFormat();  // 是否格式
@Nullable public Integer getColor(); // RGB 颜色值
public String getName();    // 小写名（如 "red"）
public String toString();   // "§" + code
public static String stripFormatting(@Nullable String input); // 去掉全部 §x 颜色码
public static ChatFormatting getByName(@Nullable String name); // 按名字查（含 cleanName 归一化）
public static ChatFormatting getByCode(char code);            // 按码查
public static Collection<String> getNames(boolean getColors, boolean getFormats);
```
- 常量 `PREFIX_CODE = '§'`。
- 特殊：`RESET('r', -1, null)`，`getColor()` 对格式码返回 null。

## 三、ClientInput（已核实存在）

- 全限定名：`net.minecraft.client.player.ClientInput`
- 源码路径：`net/minecraft/client/player/ClientInput.java`
- 注解：`@Environment(EnvType.CLIENT)`
- 关键成员（真实签名）：
  ```java
  public class ClientInput {
      public Input keyPresses = Input.EMPTY;   // 按键位集（forward/backward/left/right/jump/shift/sprint）
      protected Vec2 moveVector = Vec2.ZERO;   // 移动向量 XZ
      public void tick();
      public Vec2 getMoveVector();
      public boolean hasForwardImpulse();      // moveVector.y > 1e-5
      public void makeJump();                  // 构造带 jump=true 的新 Input
  }
  ```
- 依赖类 `net.minecraft.world.entity.player.Input`（record，字段 `forward/backward/left/right/jump/shift/sprint`，含 `EMPTY`）。
- 相关：`net.minecraft.client.player.KeyboardInput`（`KeyboardHandler` 派生的 `ClientInput` 子类，实际移动输入实现）。

## 五、平台 / 操作系统工具（已核实）

- **`net.minecraft.util.Util.getPlatform()`**（真实存在）：
  ```java
  public static Util.OS getPlatform() {
      String osName = System.getProperty("os.name").toLowerCase(Locale.ROOT);
      // win → WINDOWS; mac → OSX; solaris/sunos → SOLARIS; linux/unix → LINUX; 其余 → UNKNOWN
  }
  public static boolean isAarch64();      // OS 架构是否 aarch64
  ```
- 内部枚举 `Util.OS`（真实）：
  ```java
  public static enum OS {
      LINUX("linux"), SOLARIS("solaris"),
      WINDOWS("windows") { ... openUri 实现 ... },
      OSX("mac") { ... openUri 实现 ... },
      UNKNOWN("unknown");
      public void openUri(URI uri);  // 用系统默认方式打开链接/文件
  }
  ```
- **`mc.platform`**：26.1.2 Mojang 源码中**不存在**名为 `mc.platform` 的类/字段。平台判断请用 `Util.getPlatform()`；渲染平台底层在 `com.mojang.blaze3d.platform.*`（`Window`、`Monitor`、`GLX`、`TextureUtil`、`InputConstants`、`ClipboardManager` 等，属渲染基础设施，非通用平台抽象）。

## 六、方块交互与方块查询（补充：真实入口）

- `net.minecraft.client.multiplayer.MultiPlayerGameMode`：客户端方块交互（`startDestroyBlock`、`continueDestroyBlock`、`useItemOn` 等）。
- `net.minecraft.world.InteractionHand`（`MAIN_HAND`/`OFF_HAND`）、`net.minecraft.world.InteractionResult`（`SUCCESS/CONSUME/PASS/FAIL`）。
- `net.minecraft.world.phys.BlockHitResult`：方块命中结果（详见《碰撞.md》）。
- `net.minecraft.world.level.BlockGetter`（接口）：方块查询，关键方法 `getBlockState(BlockPos)`、`getBlockEntity(BlockPos)`，以及默认方法 `clip(ClipContext)`、`isBlockInLine(ClipBlockStateContext)`（详见《碰撞.md》）。
- `net.minecraft.world.level.BlockAndTintGetter`（继承 `BlockGetter`）：客户端世界实现的接口。

## 常见坑

1. **`ChatFormatting` 在根包**：import 是 `net.minecraft.ChatFormatting`，不是 `net.minecraft.util.ChatFormatting`。
2. **`getColor()` 可能为 null**：`BOLD`/`RESET` 等非颜色项返回 null，别直接 `getColor()` 硬算 RGB。
3. **`MutableComponent` 是类不是接口**：写法 `MutableComponent m = Component.literal("x");`，不要 `implements MutableComponent`。
4. **`Component.literal(...)` 返回 `MutableComponent`**：可直接链式 `withStyle(...)`。
5. **`ClientInput` 需要 `@Environment(CLIENT)`**：仅客户端可用；移动向量读 `getMoveVector()`。
6. **平台判断用 `Util.getPlatform()`**：不存在 `mc.platform`；`Util.getPlatform()` 每次读系统属性，可缓存结果。
7. **方块交互不在 `Util`**：破坏/放置方块用 `MultiPlayerGameMode`；碰撞/命中用 `BlockHitResult` + `BlockGetter.clip`。
8. **`openUri` 是 `Util.OS` 的方法**：打开网页/文件应 `Util.getPlatform().openUri(uri)`，注意捕获 `IOException`（内部已 try）。
9. **时间戳**：高频记时用 `Util.getMillis()`，避免自己 `System.currentTimeMillis()` 与游戏时间源不一致。
