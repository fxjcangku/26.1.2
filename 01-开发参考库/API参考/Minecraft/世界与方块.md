# 世界与方块（World & Block）

> 源码依据：Minecraft原始源码/net/minecraft/world/level/ 与 net/minecraft/client/multiplayer/ 26.1.2 Mojang官方映射

## Level（net.minecraft.world.level.Level）

- 包名：`net.minecraft.world.level`
- 源码路径：`net/minecraft/world/level/Level.java`
- 继承与接口：`public abstract class Level implements LevelAccessor, AutoCloseable`。
- 它是双端世界的共同基类；客户端具体类是 `ClientLevel`，服务端是 `ServerLevel`。Meteor 客户端拿到的 `mc.level` 是 `ClientLevel`，但当作 `Level` 用即可。

### 关键方法（签名照抄源码）

```java
public boolean isClientSide();          // 是否客户端世界（ClientLevel 恒 true）
public BlockState getBlockState(BlockPos pos);       // 取方块状态
public FluidState getFluidState(BlockPos pos);       // 取流体
@Nullable
public BlockEntity getBlockEntity(BlockPos pos);     // 方块实体（可能 null）
public boolean setBlock(BlockPos pos, BlockState state, @Block.UpdateFlags int updateFlags);
public boolean setBlockAndUpdate(BlockPos pos, BlockState blockState);
public boolean removeBlock(BlockPos pos, boolean movedByPiston);          // 设为空气
public boolean destroyBlock(BlockPos pos, boolean dropResources, @Nullable Entity breaker, int updateLimit);
public void updateNeighborsAt(BlockPos pos, Block sourceBlock, @Nullable Orientation orientation);
public boolean isLoaded(BlockPos pos);             // 该区块是否已加载
public boolean isInWorldBounds(BlockPos pos);      // 是否在世界边界内

// 时间
public long getGameTime();                         // (重写在子类) 游戏 tick 总数
public int getSkyDarken();                         // 天空变暗系数

// 实体查询（客户端常用做射线/检测）
public List<Entity> getEntities(@Nullable Entity except, AABB bb, Predicate<? super Entity> selector);
public <T extends Entity> List<T> getEntities(EntityTypeTest<Entity, T> type, AABB bb, Predicate<? super T> selector);
public void playLocalSound(Entity sourceEntity, SoundEvent sound, SoundSource source, float volume, float pitch);
public void addParticle(ParticleOptions particle, double x, double y, double z, double xd, double yd, double zd);
```

> `getMinY()/getMaxY()/getSeaLevel()` 等高度相关方法在 `Level`/`LevelHeightAccessor` 上，`ClientLevel` 直接可用（源码 `Level.java` 第 347、350 行用到 `getMinY()/getSeaLevel()`）。

## ClientLevel（net.minecraft.client.multiplayer.ClientLevel）

- 包名：`net.minecraft.client.multiplayer`
- 源码路径：`net/minecraft/client/multiplayer/ClientLevel.java`
- 继承与接口：`public class ClientLevel extends Level implements BlockAndTintGetter, CacheSlot.Cleaner<ClientLevel>`（`@Environment(EnvType.CLIENT)`）。

### 要点
- `Minecraft.getInstance().level`（`public ClientLevel level`）就指向它，未进世界为 null。
- 每 tick 在 `tick(BooleanSupplier)` 中推进游戏时间、世界边界、区块 tick 与实体 tick。
- 大部分查询直接用基类 `Level` 的方法即可；需要遍历全部实体时用 `Level.getEntities(...)`。

## BlockPos（net.minecraft.core.BlockPos）

- 包名：`net.minecraft.core`
- 源码路径：`net/minecraft/core/BlockPos.java`
- 继承与接口：`public class BlockPos extends Vec3i`（`@Immutable`，不可变）。

### 关键静态方法与常量（签名照抄源码）

```java
public static final BlockPos ZERO = new BlockPos(0, 0, 0);
public static BlockPos containing(double x, double y, double z);   // 向下取整转方块坐标
public static BlockPos containing(Position pos);
public static BlockPos min(BlockPos a, BlockPos b);
public static BlockPos max(BlockPos a, BlockPos b);
public static BlockPos of(long blockNode);            // 从打包 long 还原
public static long asLong(int x, int y, int z);       // 打包成 long（区块节存储用）
public static Iterable<BlockPos> withinManhattan(BlockPos origin, int reachX, int reachY, int reachZ);
public static Iterable<BlockPos> betweenClosed(BlockPos a, BlockPos b);
public static Iterable<BlockPos> betweenClosed(AABB box);
```

继承自 `Vec3i` 的常用方法：`getX()/getY()/getZ()`、`above()/below()/north()/south()/west()/east()`、`relative(Direction)`、`offset(x,y,z)`、`distManhattan`、`distChessboard`、`closerThan(Vec3i, double)`。全部**返回新对象**，不改动原 `BlockPos`。

### MutableBlockPos
源码 `net/minecraft/core/BlockPos.java` 内部有 `MutableBlockPos`（可变版本），用于高频循环避免反复分配。客户端 addon 临时处理循环时若需改坐标，用 `new BlockPos.MutableBlockPos()` 然后 `.set(x,y,z)`。

```java
// 来自 StateHolder<Block, BlockState>（属性读写）

public boolean hasProperty(Property<?> property);
public Collection<Property<?>> getProperties();
```

### 26.1.2 注意
- 26.1.2 的 `BlockState` **没有**简单的 `is(Block)` / `is(TagKey<Block>)` 方法（源码只有 `is(TagKey<Block> tag, Predicate<BlockStateBase> predicate)`）。比较方块用 `state.getBlock() == Blocks.STONE` 或 `state.getBlock().builtInRegistryHolder().is(...)`。
- `setValue` 返回**新** `BlockState`，原状态不变；`BlockState` 值语义（`equals`/`hashCode` 已按属性和 block 重写，`StateHolder` 第 54/58 行），可直接当 Map 键。
- 放方块推荐 `level.setBlockAndUpdate(pos, newState)`，会同步邻居与发包。

## 方块获取/破坏（MultiPlayerGameMode，客户端游戏模式）

- 源码路径：`net/minecraft/client/multiplayer/MultiPlayerGameMode.java`
- 获取：`Minecraft.getInstance().gameMode`（`public MultiPlayerGameMode gameMode`）。

### 关键方法（签名照抄源码）

```java
public boolean startDestroyBlock(BlockPos pos, Direction direction);   // 开始挖掘（客户端预测 + 发包）
public void stopDestroyBlock();                                        // 停止挖掘
public boolean continueDestroyBlock(BlockPos pos, Direction direction); // 继续挖掘（返回是否挖完）
public boolean destroyBlock(BlockPos pos);                             // 服务端确认破坏
public void tick();                                                    // 每 tick 推进挖掘进度/方块破坏

public InteractionResult useItemOn(LocalPlayer player, InteractionHand hand, BlockHitResult blockHit); // 对块用物品
public InteractionResult useItem(Player player, InteractionHand hand);                   // 使用手中物品
public void attack(Player player, Entity entity);                        // 攻击实体（发包）
public InteractionResult interact(Player player, Entity entity, EntityHitResult hitResult, InteractionHand hand);
public void handlePickItemFromBlock(BlockPos pos, boolean includeData);  // 中键拾取方块（发包）
public void handlePickItemFromEntity(Entity entity, boolean includeData);// 中键拾取实体

public GameType getPlayerMode();          // 当前游戏模式（客户端权威）
public GameType getPreviousPlayerMode();  // 上个模式

public boolean isDestroying();            // 是否正在挖掘
```

> 客户端 addon 模拟“破坏方块”要走 `gameMode.startDestroyBlock/continueDestroyBlock` 触发客户端预测并最终发包，而不是直接 `level.destroyBlock(...)`（那只改本地世界，服务端不认可）。

## 常见坑

1. **`mc.level` / `mc.player` 判空**：未进世界为 null，先判空再取方块/实体。
2. **`BlockPos` 不可变**：`pos.above()` 等返回新对象；写循环时用 `MutableBlockPos` 避免 GC 压力；`BlockPos` 当 Map 键安全。
3. **`BlockState` 没有 `is(Block)`**：26.1.2 已去掉，旧代码 `state.is(Blocks.STONE)` 会编译失败，改用 `state.getBlock() == Blocks.STONE`。
4. **改方块要记得同步**：`level.setBlock` 只改本地；要完整效果用 `setBlockAndUpdate`（触发邻居更新 + 渲染更新）；客户端主动放置方块应走 `gameMode` 交互路径而非裸 `setBlock`。
5. **`getBlockEntity` 可能返回 null**：方块实体只存在于部分方块，取完先判 null 再 `.getComponent()` 类读写；容器类要用 `getBlockEntity` 后强转 `Container` 再操作。
