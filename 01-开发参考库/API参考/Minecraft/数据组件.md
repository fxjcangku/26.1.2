# 数据组件（Data Components）

> 源码依据：Minecraft原始源码/net/minecraft/core/component/ 与 net/minecraft/world/item/component/ 26.1.2 Mojang官方映射

1.21.4+ 起（含 26.1.2），物品不再附带 NBT 复合标签（`NbtCompound`/Yarn 旧名），全部属性一分为「数据组件体系」：每个组件是一个注册的 `DataComponentType<T>`，物品堆携带一份 `DataComponentMap`。

---

## DataComponents（net.minecraft.core.component.DataComponents）

- 包名：`net.minecraft.core.component`
- 源码路径：`net/minecraft/core/component/DataComponents.java`
- 所有组件 type 的注册常量都在这，命名 `大写_蛇形`。客户端 addon 读写物品属性就靠它。

## DataComponentType（net.minecraft.core.component.DataComponentType）

- 源码路径：`net/minecraft/core/component/DataComponentType.java`
- 继承与接口：`public interface DataComponentType<T>`。

```java
static <T> DataComponentType.Builder<T> builder();   // 构建器
@Nullable Codec<T> codec();                          // 持久化编解码器（null=transient）
default Codec<T> codecOrThrow();                      // 无 codec 抛异常
default boolean isTransient();                        // codec()==null（不落盘）
boolean ignoreSwapAnimation();                        // 交换是否播动画
StreamCodec<? super RegistryFriendlyByteBuf, T> streamCodec(); // 网络同步编解码
```

`Builder` 链式调用：`.persistent(Codec)`（可落盘）、`.networkSynchronized(StreamCodec)`（可发包）、`.cacheEncoding()`、`.ignoreSwapAnimation()`。

## DataComponentMap（net.minecraft.core.component.DataComponentMap）

- 源码路径：`net/minecraft/core/component/DataComponentMap.java`
- 继承与接口：`public interface DataComponentMap extends Iterable<TypedDataComponent<?>>, DataComponentGetter`。
- 组件快照（不可变），`ItemStack.getComponents()` 返回它。

```java
DataComponentMap EMPTY;
static DataComponentMap composite(DataComponentMap prototype, DataComponentMap overrides); // 合并 prototype+overrides
static DataComponentMap.Builder builder();

Set<DataComponentType<?>> keySet();
default boolean has(DataComponentType<?> type);
default int size(); default boolean isEmpty();
default DataComponentMap filter(Predicate<DataComponentType<?>> predicate);

// Builder
public <T> DataComponentMap.Builder set(DataComponentType<T> type, @Nullable T value);
public DataComponentMap.Builder addAll(DataComponentMap map);
public DataComponentMap.Builder addValidator(Consumer<DataComponentMap> validator);
public DataComponentMap build();
```

## DataComponentHolder / DataComponentGetter（net.minecraft.core.component）

- 路径：`net/minecraft/core/component/DataComponentHolder.java`、`DataComponentGetter.java`
- `DataComponentGetter`：`@Nullable <T> T get(DataComponentType<? extends T> type);` + `getOrDefault`、`getTyped`。
- `DataComponentHolder extends DataComponentGetter`：加了 `getComponents()`、`getAllOfType(Class)`、`has(type)`。`ItemStack` 实现它。

```java
DataComponentMap getComponents();
default <T> Stream<T> getAllOfType(Class<? extends T> valueClass); // 按值类型流式取出
```

## ItemStack 组件读写（真实签名）

```java
public <T> T get(DataComponentType<? extends T> type);                          // 读，缺省 null
public <T> T getOrDefault(DataComponentType<? extends T> type, T defaultValue); // 读，缺省回退
public <T> T set(DataComponentType<T> type, @Nullable T value);                 // 写（null 删除），返回旧值
public <T> T remove(DataComponentType<? extends T> type);                       // 删，返回旧值
public <T> T update(DataComponentType<T> type, T defaultValue, UnaryOperator<T> fn);          // 原子读改写
public <T, U> T update(DataComponentType<T> type, T defaultValue, U value, BiFunction<T,U,T> cb);
```

### 典型用法

```java
// 读附魔
ItemEnchantments enc = stack.get(DataComponents.ENCHANTMENTS);
int level = stack.getEnchantments().getLevel(Enchantments.SHARPNESS); // 见 附魔.md

// 写显示名（IronAnvil 命名）
stack = stack.set(DataComponents.CUSTOM_NAME, Component.literal("神剑"));

// 累加修复惩罚
stack = stack.update(DataComponents.REPAIR_COST, 0, cost -> cost + 2);

// 任意数据（等效旧 getOrCreateTag）
CustomData data = stack.getOrDefault(DataComponents.CUSTOM_DATA, CustomData.EMPTY);
```

## 常见坑

1. **`ItemStack.getComponents()` 返回的是**快照，改它不影响物品；改物品必须 `stack = stack.set/update(...)` 重新赋值，别在旧的 `stack` 上继续读。
2. **`set(type, null)` 是删除**：`set` 传 `null` 等价 `remove`；区分「写 0」「写空字符串」与「删组件」——前者 value 非 null，后者 value==null。
3. **`DataComponentType` 有 transient 概念**：`isTransient()`（无 `codec()`）的组件不落盘、只存在网络/内存。给自定义组件绑 `codec` 才可持久化；`DataComponentType.PERSISTENT_CODEC` 会拒绝 transient 类型。
4. **`CUSTOM_DATA` 不是「万能口袋」**：它只是普通 `DataComponentType<CustomData>`，要带 `codec` 的数据结构才能塞进去；别把 `NbtCompound`（已删除）当成可存类型。
5. **`DataComponentMap` 不可变 + keySet 不可改**：`keySet()` 返回的是只读视图，遍历请用 `for (TypedDataComponent<?> e : components)` 或 `stream()`，不能 `map.keySet().remove(...)`。
6. **网络同步 vs 持久是两套 codec**：`.persistent()` 只管存盘，跨服/发包要 `.networkSynchronized()`；只写一个会导致另一边丢数据。
