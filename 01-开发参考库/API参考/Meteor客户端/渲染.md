# 渲染

> 源码依据：Meteor原始源码/meteordevelopment/meteorclient/renderer/... 与 utils/render/color/... Meteor Client 26.1.2-SNAPSHOT

Meteor 26.1.2 的渲染系统**已彻底重写为 MeshBuilder + RenderPipeline 架构**（不再用旧的 `DrawContext`/`VertexConsumer` 直接绘制）。本文整理 `Renderer2D` / `Renderer3D` / `MeshBuilder` / `ShapeMode` / `Color` 与 `Render2DEvent` / `Render3DEvent`，并以真实模块 `AirPlace` 的 `onRender(Render3DEvent)` 提供骨架。

> ⚠️ 重要变化：26.1.2 中 `Renderer2D` **没有** `circle` / `unfilledCircle` 方法（旧版 API 已移除），也没有独立的 `Mesh.java`（已由 `MeshBuilder` 取代）。

## 真实 3D 渲染骨架（摘自 AirPlace.java）

源码：`systems/modules/player/AirPlace.java`。这是 26.1.2 标准 `@EventHandler` 监听 `Render3DEvent` 的写法：

```java
@EventHandler
private void onRender(Render3DEvent event) {
    if (!(hitResult instanceof BlockHitResult bhr)
        || (mc.hitResult != null && mc.hitResult.getType() != HitResult.Type.MISS)
        || !mc.level.getBlockState(bhr.getBlockPos()).canBeReplaced()
        || !InvUtils.testInHands(this::placeable)
        || !render.get()) return;

    event.renderer.box(bhr.getBlockPos(), sideColor.get(), lineColor.get(), shapeMode.get(), 0);
}
```

要点：
1. `event.renderer`（或 `event.depthRenderer`）直接拿到 `Renderer3D`，**不需要** `begin()/render()` 包裹——框架已替你管理 begin/render。
2. `sideColor.get()` / `lineColor.get()` 是 `Setting<SettingColor>` 的取值（`SettingColor` 可隐式当 `Color` 用）。
3. 颜色要用 `Color` / `SettingColor`，不再直接传 `java.awt.Color`。

对应模块设置（照抄真实字段名）：

```java
private final Setting<ShapeMode> shapeMode = sgGeneral.add(new EnumSetting.Builder<ShapeMode>()
    .name("shape-mode").defaultValue(ShapeMode.Both).build());
private final Setting<SettingColor> sideColor = sgGeneral.add(new ColorSetting.Builder()
    .name("side-color").defaultValue(new SettingColor(204, 0, 0, 10)).build());
private final Setting<SettingColor> lineColor = sgGeneral.add(new ColorSetting.Builder()
    .name("line-color").defaultValue(new SettingColor(204, 0, 0, 255)).build());
```

### 2D 渲染骨架
```java
@EventHandler
private void onRender2D(Render2DEvent event) {
    Renderer2D.COLOR.begin();
    Renderer2D.COLOR.boxLines(x, y, w, h, Color.RED);
    Renderer2D.COLOR.quad(x, y, w, h, new Color(255, 0, 0, 80));
    Renderer2D.COLOR.end();
    Renderer2D.COLOR.render();
}
```

## 常见坑
1. 旧 `Renderer2D.circle(...)` / `unfilledCircle(...)` **已删除**，迁移代码须改用 `line`/`boxLines`/`quad` 手绘或三角扇。
2. 不要在 `Render3DEvent` 里手工调 `event.renderer.begin()/render()`——事件分发方已经做了 begin/render；重复调用会抛「already building」异常。
3. 颜色对象 `Color` 字段可变，跨帧复用同一个 `Color` 实例做渐变时注意要 `copy()`（`set` 会原地修改）。
4. 3D 顶点基于「减去摄像机坐标」的世界坐标，传入世界绝对坐标即可，不必手动换算。
5. `boxLines`/`boxSides`/`box` 的 `excludeDir=0` 表示画全六面；非 0 需用 `Dir.*` 位标志组合。
6. `SettingColor` 而非 `Color` 用于 `@Setting`（含序列化与彩虹支持）；运行时绘制可两者混用。
