================================================================
  [yiyiaddon] 反编译警告 / DECOMPILE WARNING
================================================================

能看到这个文件，说明你正在反编译、逆向或试图"破解"这个 addon。

在继续之前，请先花一分钟读完下面的话，再决定要不要浪费这个时间。

----------------------------------------------------------------
一、你正在面对的是什么
----------------------------------------------------------------

这个文件不是普通的「打包后没做保护的 jar」。它经过了多层加固：

1. 改名混淆（ProGuard）
   - 所有类名、方法名、字段名被重命名为 O0 / l1 / I1 / Il 这类
     肉眼几乎无法区分的字符组合
   - 通过 repackageclasses 打乱了原始包结构，看不到任何
     「mining / farm / villager」这类语义化的包名

2. 方法重载混淆（overloadaggressively）
   - 大量方法被合并成同名重载，单靠名字根本无法区分功能

3. 字符串加密
   - 方法体内的字符串常量全部被加密成 Base64 密文
   - 运行时才通过解密方法还原，反编译出来是一堆乱码
   - 你想靠「搜索中文提示」来定位代码，这条路已经断了

4. 控制流混淆（optimize）
   - 方法体被内联、常量被折叠、控制流被改写
   - 反编译出来的代码和原始逻辑完全对不上，读起来像天书

5. 调试信息全删
   - 行号、局部变量表、方法签名、内部类信息全部移除
   - 断点调试、变量名还原，想都别想

----------------------------------------------------------------
二、反编译出来你会得到什么
----------------------------------------------------------------

大概率是一份这样的东西：

    public final class O0lI1 {
        public static String O0(String IIl) {
            return I1I.O0O(IIl, "l1l");
        }
    }

    - 类名、方法名没有任何意义
    - 字符串是一堆密文，看不到任何业务逻辑
    - 控制流被打乱，逻辑关系无法还原

----------------------------------------------------------------
三、复原要花多少时间
----------------------------------------------------------------

诚实地说，不是「不可能」，而是「不划算」：

- 你需要逐类、逐方法地手工还原语义
- 光是搞清楚一个类的功能，可能就要半天
- 全部几十个类、几百个方法，这是以「天 / 周」为单位的
  枯燥体力活，而且极易出错
- 更现实的是：等你还原完，作者可能早就更新了好几个版本

----------------------------------------------------------------
四、更关键的一点：值钱的东西不在这里
----------------------------------------------------------------

这个客户端 addon 只负责「上报数据」，不做任何「决策」：

- 核心逻辑、鉴权、数据处理全部在服务端（Cloudflare Worker）
- 密钥 / 密码 / Token 全部走服务端环境变量，客户端里根本没有
- 你逆向出客户端，最多知道它往哪个接口发了什么格式的数据
  —— 而这个接口本身也是要鉴权的

所以即使你完整复原了整个客户端，也拿不到任何有价值的东西。

----------------------------------------------------------------
五、最后的建议
----------------------------------------------------------------

如果这个 addon 里有你想要的功能，与其花几十个小时
逆向一份面目全非的字节码，不如：

    自己写一个。

—— 真的，你自己写一个，都比我把它复原出来要快。
