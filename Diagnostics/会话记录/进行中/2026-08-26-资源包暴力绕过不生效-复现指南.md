# 复现指南：资源包暴力绕过不生效

**会话**：`ServerDetector-资源包`  
**日期**：2026-08-26  
**构建版本**：已编译 `build/libs/yiyiaddon1.1-personal.jar`

---

## 一、启动监听服务

```powershell
node Diagnostics\工具\调试监听服务.js
```

监听器会在 `http://127.0.0.1:7777/event` 接收埋点，写入 `Diagnostics/运行日志/ServerDetector-资源包_本次复现_YYYYMMDD_HHMMSS.ndjson`。

---

## 二、复现步骤

### 场景 1：暴力绕过模式

1. 加载 mod，开启 `ServerDetector` 模块
2. 设置 **资源包模式 = 暴力绕过**
3. 进入发送资源包的服务器（如 Hypixel、某些小游戏服）
4. 观察：
   - 是否仍显示资源包加载界面？
   - 聊天栏是否提示"已拦截资源包请求（暴力绕过）"？

### 场景 2：自动白嫖模式

1. 设置 **资源包模式 = 自动白嫖**
2. 设置 **重试次数 = 5**、**读取超时 = 60秒**、**断点续传 = 开启**
3. 进入发送资源包的服务器
4. 观察：
   - 是否提示"开始下载资源包"？
   - 下载是否成功？若失败，是否有错误提示？
   - 检查 `yiyiaddon_resourcepacks/` 目录，是否生成 `.zip` 或 `.zip.part` 文件？

## 四、关键证据点

**暴力绕过失效**，需证实：
- [ ] `handleResourcePackRequest` 是否被调用？
- [ ] `resourcePackMode.get()` 返回值是否为 `BYPASS`？
- [ ] `event.setCancelled(true)` 是否执行？
- [ ] `ACCEPTED` 与 `SUCCESSFULLY_LOADED` 状态包是否发送？

**下载失败**，需证实：
- [ ] `downloadAsync` 是否启动？
- [ ] HTTP 响应码是什么？（200/206/403/416/500...）
- [ ] 是否超时？异常类型是什么？
- [ ] 断点续传是否生效？（看 `offset` 与响应码 206）
- [ ] SHA-1 校验是否通过？
- [ ] 重命名是否成功？

## 五、预期假设排查顺序

1. **假设 A**：方法未执行 → 检查事件监听器优先级、`isActive()` 状态
2. **假设 B**：模式判断错误 → 检查配置读取逻辑
3. **假设 C**：取消事件无效 → 检查其他监听器冲突、事件取消时机
4. **假设 D**：协议变更 → 检查包类型、Mojang 映射变化
5. **下载失败子假设**：
   - 网络问题（超时、403）
   - 服务端不支持 Range
   - SHA-1 不匹配
   - 文件系统权限问题
