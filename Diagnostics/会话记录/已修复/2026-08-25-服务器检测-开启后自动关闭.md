## 症状

多人服务器中开启「服务器检测」，聊天栏出现：

```
[23:44:53] [yiyiaddon][服务器检测]已开启
[23:44:54] [yiyiaddon][服务器检测]已关闭
```

间隔约 1 秒，期间没有出现「单人世界无需检测」提示。

## 影响范围

- 直接模块：`com.example.addon.tactical.ServerDetector`
- 实际根因层：`com.example.addon.core.YiyiaddonModule`（基类，影响全部 yiyiaddon 模块）

## 复现前提与步骤

1. 进入多人服务器（非单人世界）
2. 打开 Meteor GUI，点击开启「服务器检测」
3. **关闭 GUI**（按 Esc 或再按 Right Shift）
4. 模块随即变为「已关闭」

关键修正：触发条件不是「等待 1 秒」，而是**关闭 GUI 的那一刻**。截图里的 1 秒间隔只是用户点完开关到关掉界面的手速。

## 可证伪假设

| ID | 假设 | 判定依据 | 结论 |
|----|------|----------|------|
| H1 | `onActivate()` 环境判定异常（世界或连接为空） | H1 事件的 `world` / `connection` | ❌ 排除，两者恒为 `true` |
| H2 | 单人世界分支误命中，模块自我关闭 | 是否出现 H2 事件 | ❌ 排除，H2 事件从未出现，且 `hasSingleplayerServer=false` |
| H3 | 外部调用方触发关闭 | H4 调用栈来源 | ✅ **确认**，来自 `Modules.onOpenScreen` |
| H4 | 基类 `toggle()` 与 Meteor 核心互相递归 | H4 事件次数与 `activeBefore` 序列 | ❌ 排除，每轮开关各一次，无递归 |

## 埋点位置

均在 [ServerDetector.java](file:///d:/mcaddon/26.1.2/src/main/java/com/example/addon/tactical/ServerDetector.java)，以 `// #region debug-point` 标记：

## 根因

Meteor 核心 `Modules.onOpenScreen` 的逻辑：

```java
@EventHandler(priority = EventPriority.HIGHEST + 1)
private void onOpenScreen(OpenScreenEvent event) {
    if (!Utils.canUpdate()) return;
    for (Module module : moduleInstances.values()) {
        if (module.toggleOnBindRelease && module.isActive()) {
            module.toggle();
            module.sendToggledMsg();
        }
    }
}
```

进入这个分支的唯一条件是 `toggleOnBindRelease == true`。

而源码里这个字段早已删除（全项目 grep 零匹配），关键在 `Module.fromTag`：

```java
toggleOnBindRelease = tag.getBooleanOr("toggleOnKeyRelease", false);
```

早期版本设过 `this.toggleOnBindRelease = true`，该值被序列化写进了 `modules.nbt`。**删掉代码不影响已存盘的配置**——每次启动客户端，`fromTag` 都会把 `true` 从 NBT 里读回内存，模块又变成「关闭 GUI 时自动关」。

这解释了上一轮会话（`服务器检测-开关异常-旧.md`）为什么标了 CLOSED 但问题依旧：那次只删了赋值语句，没有处理配置残留。

## 最小修复

在基类 [YiyiaddonModule.java](file:///d:/mcaddon/26.1.2/src/main/java/com/example/addon/core/YiyiaddonModule.java) 两处压制该字段，覆盖构造与读档两条路径：

```java
protected YiyiaddonModule(Category category, String name, String description) {
    super(category, name, description);
    toggleOnBindRelease = false;
}

@Override
public Module fromTag(CompoundTag tag) {
    Module result = super.fromTag(tag);
    toggleOnBindRelease = false;   // 抹掉 modules.nbt 里的历史残留
    return result;
}
```

放基类而非 `ServerDetector`，因为任何 yiyiaddon 模块只要历史配置里带了这个标记都会中招。
