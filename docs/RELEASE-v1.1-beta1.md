## 📦 安装说明

1. 下载 `yiyiaddon1.1-beta1.jar` 放入 `.minecraft/mods/` 文件夹
2. 启动游戏，按 <kbd>Right Shift</kbd> 打开 Meteor 菜单
3. 在 `yiyiaddon 工具` 🛠️ 分类中找到所有模块
4. Baritone 已内置，无需额外安装
