# AutoMiner 配置页面排版

```
┌─ ⚙️  目标选择

│
├─ 📊 阈值设置
│   ├─ [20] 满载组数 (1-36)
│   ├─ [12] 饥饿阈值 (1-20)
│   └─ [50] 耐久阈值 (1-500)
│
├─ 🌐 指令配置
│   ├─ 去野外指令
│   ├─ 满载卸货指令

│
├─ 🤖 Baritone设置
│   ├─ [✓] 避开岩浆

│   ├─ [✓] 破坏阻挡方块
│   ├─ [ ] 放置方块

    ├─ [1.0] ESP字体大小 (0.5-3.0)

    ├─ [🟢] 食物箱颜色
    └─ [🟣] 挂机点颜色
```

---

## 设计逻辑

### 1️⃣ 目标选择（第一步）
- **必填项**，决定挖什么
- 放在最前面，引导用户先选目标

### 2️⃣ 阈值设置（第二步）
- **核心参数**，决定何时触发卸货/补给/修补
- 紧随目标后，配置基本行为逻辑

### 3️⃣ 指令配置（第三步）
- **必填项**，5条指令决定传送路径
- 放在前面，确保用户不遗漏

### 4️⃣ Baritone设置（第四步）
- **优化项**，控制寻路行为
- 有默认值，可跳过，适合进阶用户调整

### 5️⃣ 垃圾丢弃（第五步）
- **辅助项**，已有默认值
- 放在后面，不影响核心功能

### 6️⃣ 显示设置（最后）
- **美化项**，纯视觉调整
- 放在最后，用户配置完功能后再调整显示

---

## 人性化特点

✅ **按使用流程排序**：目标 → 阈值 → 指令 → 优化 → 美化
✅ **必填项前置**：目标、阈值、指令放在前3位
✅ **可选项后置**：Baritone、垃圾、显示放在后面
✅ **逻辑分组清晰**：每组功能单一，不混杂
✅ **默认值友好**：新手不调也能用，老手可深度优化
