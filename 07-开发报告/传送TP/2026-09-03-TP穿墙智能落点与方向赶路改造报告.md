# 2026-09-03-TP穿墙智能落点与方向赶路改造报告

## 一、改造目标
按用户十五条正式要求，把 TP穿墙 从「准星命中墙体 → 出口点下落」的旧式机械逻辑，
改造成「触发瞬间锁定真实三维视线快照 → 沿射线智能搜索最远可容纳落点 → 局部修正 → 执行 → 服务端验证」的完整体系，
并同时承担「穿墙」与「方向赶路」两种用途，不新增第二套子系统。

## 二、改动文件清单

### 1. teleport/geo/WallRayScanner.java（核心重构）
- 删除旧 DDA 出口点扫描与 `dropToStand`，重写为 `findLanding` 三维方向落点扫描器。
- 机制：从视线起点 2 格外沿锁定三维射线以 0.5 格步长采样至「最大穿墙距离」（默认 32）：
  - 每个采样点把视点向下映射 eyeHeight 得到脚部基准，基准向下最多 maxFall 找第一个通过完整安全判据的高度（台阶式落支撑）；
  - 取射线进展最远的候选（方向一致性 + 距理想区最近 + 真实容纳同时满足）；
  - 沿途普通方块/门窗/半砖/栅栏一律**只统计不阻挡**（穿透层数仅供播报），无墙时照样前进；
  - 未知区块立即终止采样（`reachedUnloaded`）；射线耗尽仍在实体内部则标记 `exhaustedInsideSolid`（障碍太厚）；
  - 全程无候选时返回 `idealFeet`（扫描终点脚部映射）作为外层局部修正中心。

### 2. teleport/core/TeleportCoordinator.java（决策与生命周期）
- WALL 分支重写：调 `findLanding` 主路取点；主路无候选时先区分三种失败——
  「前方世界数据未加载」「障碍太厚，超出最大穿墙距离」「步入局部修正」；
- 局部修正：以理想落点为中心、`落点修正范围`（默认 3）为半径调 SafePositionFinder，
  约束为「准星偏离上限 + 沿射线最短进展 2 格」（`minAhead` 新参数），绝不把玩家传回近侧或身侧；
- 新增执行前二次校验 `recheck()`：发包位移前重查 维度一致/玩家存活/目标碰撞容纳/危险变化，任一失效取消执行；
- 回弹播报从「⚠ 警告」改为「✗ 传送失败 ▸ 服务器位置被修正」并保留偏差数值（仍无自动重试、无重复发包）；
- 成功播报：穿墙层数仅在 >0 时显示；局部修正命中时显示「局部修正 X 格」；
- 删除死代码 `dot()` 辅助方法。

### 3. teleport/safety/SafePositionFinder.java
- `SearchParams` 新增 `minAhead`（穿墙约束候选沿射线最短进展，默认 0 不影响坐标模式）。

### 4. teleport/model/TeleportRequest.java
- 新增 `eyeHeight`（触发瞬间玩家眼高，视点→脚部映射用，默认 1.62）。

### 5. modules/TeleportModule.java
- 触发穿墙时快照 `getEyePosition / getViewVector / getEyeHeight` 三项完整锁定；
- 设置调整：「视线射线距离」→「最大穿墙距离」默认 32（4~64）；「落点偏离上限」→「落点修正范围」默认 3（1~8）；全部保持 `.noSlider()` 加减按钮带框；
- 说明面板更新 TP穿墙/方向赶路语义；
- 修复隐藏 bug：`autoSubscribe = false` 禁用基类自动订阅，避免 toggle + onActivate 双重注册导致全部事件触发两次。

## 三、与十五条要求的对应验证
| 要求 | 落实点 |
| --- | --- |
| 1 触发瞬间锁视线 | triggerWall 一次锁三参数，执行期间鼠标移动不影响 |
| 2 同时承担赶路 | 前方无墙正常行进；仅手动按键触发，busy 锁防并发，无自动循环 |
| 3 最大搜索距离 | 「最大穿墙距离」默认 32，实际接受与否由服务端验证决定 |
| 4 完整三维方向 | 射线方向即 viewVector，上/下/斜向自然支持 |
| 5 理想点是搜索中心 | 主路无候选 → 以 idealFeet 为中心按修正范围局部搜索 |
| 6 质量排序 | 射线最远（方向+距理想）+ 真实容纳 + 无危险 + 区块有效；横向偏移受修正范围钳制 |
| 7 不把普通方块当禁止 | 全程只统计穿透层数，无黑名单、不用 isFullCube |
| 8 不完整方块落点 | CollisionSafety 全程 VoxelShape + EntityDimensions 实际碰撞箱判定 |
| 9 看着前面赶路 | 沿准星最远安全落点，连续按键逐段赶路 |
| 10 山体/建筑 | 射线不因方块停止，穿过山体直达远侧或判定太厚 |
| 11 指向天空 | 向上候选同样采样；无支撑则修正或失败，不无限上升 |
| 12 执行前再检查 | recheck() 七项复核全部覆盖 |
| 13 执行与验证 | 瞬时发包位移（非模拟移动）；回弹即失败播报，无重试无 spam |
| 14 源码组织 | 逻辑全在 geo/safety/core 分层，模块类只做面板与触发打包 |
| 15 不过度安全 | 保护项仅碰撞/岩浆火焰/虚空/未加载/维度变化/回弹六类 |

## 四、自查结果
- 编译：`buildPersonal` 通过（JDK 25，26.1.2 API）。
- mixin 注册审计：35 声明 = 35 文件，零漏注入、零死配置。
- import 对账：8 条异常全部为 brigadier/serialization/logging 库类（审计脚本仅扫客户端 jar 的已知盲区误报），非本次改动引入。
- 负面清单：teleport 包零命中；新增 API 全部为 26.1.2 官方类（`ClientLevel.hasChunk/getBlockCollisions`、`EntityDimensions.makeBoundingBox`、`ServerboundMovePlayerPacket.Pos` 等，均沿用既有编译通过路径）。
- 死代码：删除旧 DDA 工具方法与 `dot()`，无残留。

## 五、未改动且保持共享的部分
- TP地面（SurfaceScanner）、TP坐标（坐标 + 邻近回退）逻辑未动；
- 三模式仍共享：CollisionSafety 统一安全判据、SafePositionFinder 统一搜索器、
  PositionExecutor 统一执行、RubberbandVerifier 统一验证、TeleportCoordinator 统一状态机与播报。
